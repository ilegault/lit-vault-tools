# lit-vault-tools

Two manually-run commands for the literature-review Obsidian vault:

- `enrich` — fills graph metadata (institutions, authors, subfield, links between saved papers) into saved paper notes.
- `explore` — writes temporary stub previews of one paper's references and citations into `_explore/`.
